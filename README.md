# 🤖 SmartRecipe AI

SmartRecipe AI is an AI-powered recipe generator built with Flask and Google Gemini AI. Users can generate recipes, save favorites, plan meals, and manage their cooking experience through a modern web interface.

## ✨ Features

- 🤖 AI Recipe Generator
- ❤️ Favorite Recipes
- 📅 Meal Planner
- 📜 Recipe History
- 📄 PDF Export
- 📊 Dashboard
- 🔐 User Authentication
- 📧 Contact Form
- 📱 Responsive Design

## 🛠️ Tech Stack

- Python
- Flask
- SQLite
- SQLAlchemy
- Bootstrap 5
- JavaScript
- Google Gemini AI
- EmailJS

## 🚀 Installation

```bash
git clone https://github.com/Rayanabdirizak/SmartRecipe-AI.git

cd SmartRecipe-AI

pip install -r requirements.txt

python app.py
```
